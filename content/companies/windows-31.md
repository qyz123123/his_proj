### Windows 3.1: The Software That Made PCs Feel Usable

By *Yunzhe Qu*

Before the publication of Windows Operating System, most computer systems must be operated by commands typed by keyboard.

Find a file? You need type a long command in order to do so. Open a file by double clicking? No way. You'd better remember the commands. 

![Early DOS command interface](content/companies/early%20dos.jpg)

**Personal computer?** Maybe. **Personal for everyone?** Not yet.

**Windows 3.1 by Microsoft is the game changer**

You can see files list on the screen. You can operate your computer by clicking the buttons on visual interface.

![Windows 3.1 graphical interface](content/companies/windows3.1.png)

**"Make softwares that make computer work for you."** Microsoft made the software through which everybody could operate their computers easily. **Microsoft significantly lowered the barrier for operating an computer, making the adoption of computer easier than ever.**
