### Windows 3.1: The Software That Made PCs Feel Usable

Before the publication of Windows Operating System, most computer systems must be operated by commands. Find a file? You need remember and type a long command on the screen. Open a file by double clicking? No way. You should remember the file name. Then use the command "./filename" to open it. (**Historical Situation**)

![Early DOS command interface](content/companies/early%20dos.jpg)

**That is the historical context before Windows went to the public.**

**Personal computer?** Maybe. **Personal for everyone?** Not yet.

Windows 3.1 by Microsoft changed the game by introducing **graphic user interface**.

People could click the buttons that appears on the screen to operate their computer. The folders, docs, and the calculator in your computer are visualized on the screen. While, command is no more.

![Windows 3.1 graphical interface](content/companies/windows3.1.png)

**"Make softwares that make computer work for you". Microsoft Windows significantly lowered the barrier for operating an computer, making the adoption of computer easier than ever.**
